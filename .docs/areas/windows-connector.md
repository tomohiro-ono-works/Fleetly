# windows-connector

## 役割

この文書は、Windows Connector の責務範囲仕様である。

## 画面操作

- Windows のアクティブウィンドウおよびフォーカス中のコントロールに対する入力を担当する。
- 対象ウィンドウの検索・起動・前面化は担当しない。
- `mouse_click` は `coordinate_mode` で座標の取得方法を選ぶ。`current` は実行時のカーソル座標、`specified` は保存済みの X・Y座標を使う。既定値は既存flowとの互換を保つため `specified` とする。
- `specified` の X・Y座標は、直接入力または GUI の「マウスで指定する」で設定できる。
- `input_text` はフォーカス中のコントロールへ文字列を入力する。`replace` は入力前に全選択し、`append` は既存内容の末尾に入力する。日本語・改行を含む文字列は、一時的にテキストクリップボードを使用して貼り付け、元のテキストを復元する。
- `send_keys` は Ctrl / Shift / Alt の組み合わせと、英数字または定義済みの特殊キーを送信する。`wait_seconds` を指定すると、送信後にその秒数だけ待機する。
- `wait` は 0〜600 秒の整数を指定して待機する。画面要素の出現待機は初期範囲に含めない。

## 実装方針

- 画面操作は `PyAutoGUI==0.9.54` を使用する。これは `requirements.txt` に固定済みの依存である。
- 各操作は実行結果を 1 行の DataFrame として返し、操作内容と実行時刻を記録する。
- 成功時のログ出力と 1 行 DataFrame の生成は `_complete_action` に集約し、各 action は操作本体に集中する。
- Windows 以外の環境では、画面操作 action を明示的にエラーにする。

## エラー方針

- 未対応のマウスボタン、キー、入力モード、または範囲外の値は実行前にエラーにする。
- Windows API による入力送信が失敗した場合は、失敗を握りつぶさず実行エンジンへ伝播させる。
