### 保存まわり

- 保存ボタンでネイティブ保存ダイアログが必ず出るか
- 既存ファイルを開いている場合でもフォルダ変更できるか
- キャンセル時に誤保存されないか

- `output_folder` がファイル選択ではなくフォルダ選択になるか
- hidden ref の dir 編集でもフォルダ選択になるか

### ログまわり

- 起動ログ
- bridge ログ
- `ui-event`

がターミナルで確認できるか
